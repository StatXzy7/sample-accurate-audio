# 采样精确 · 语音训练片段整理

一个**完全本地运行**的网页工具，把一段语音素材整理成可复现的训练片段。重点是**采样位置**与**导出内容**逐点准确，不做任何语音识别。

- 仅依赖 **Node.js 内置能力 + 浏览器原生 API**（Canvas / Web Crypto / Web Audio 无关），零第三方包、无外部音频编解码程序。
- 输入：单声道、16-bit PCM WAV；也可一键加载程序生成的确定性短音频（8000 Hz / 1 s）。
- 输出：新的 16-bit PCM WAV + 一份来源说明 `*.manifest.json`。**原始素材永不修改。**

## 运行

```bash
npm start                 # http://127.0.0.1:8000/
node server.js --port 3000
node server.js --port 0   # 系统分配空闲端口，并在控制台打印实际地址
```

`--port 0` 输出示例：

```
采样精确音频整理工具已启动：
  http://127.0.0.1:10292/
```

然后用浏览器打开该地址（建议 Edge/Chrome/Firefox）。

## 使用流程

1. 点「导入 WAV」选择单声道 16-bit PCM WAV，或点「加载生成素材」。
2. 在源波形上**按住拖选**区间，或直接在表单输入**时间（秒）/ 采样编号**（二者双向同步），设置淡入/淡出毫秒数后「添加片段」。可建立任意多个片段。
3. 在片段表中：↑↓ 调整顺序、⧉ 重复引用同一来源区间（生成新的一条，指向同样的采样范围）、◎ 在源波形高亮定位、✕ 删除；每段可单独改淡入/淡出。
4. 设置相邻片段间的静音采样数。输出长度与输出波形**实时更新**。
5. 「导出 WAV + 来源说明」会下载两个文件，并可在页面内试听。
6. 「恢复原始编辑」回到素材刚加载时的状态（清空片段与静音，素材保留）。

## 精确性约定（界面与导出说明一致）

### 区间：左闭右开

所有片段边界都是采样编号区间 `[start, end)`：

- 包含采样 `start`，不包含采样 `end`；长度 `length = end − start`。
- 源合法采样编号为 `0 .. sampleCount−1`，右端点 `end` 最大可取 `sampleCount`。
- **拒绝**：零长度（`start === end`）、越界（`<0` 或 `> sampleCount`）、结束早于开始、非整数编号。

### 毫秒 → 采样数

```
samples = roundHalfAwayFromZero(ms / 1000 * sampleRate)
```

四舍五入，小数恰为 0.5 时向远离 0 方向进位（毫秒非负，即 0.5 向上）。
例：8000 Hz 下 `0.0625 ms → 0.5 采样 → 1`，`2.5 ms → 20`，`125 ms → 1000`。

### 线性淡入 / 淡出（只乘幅度，绝不改变长度）

片段长 `L`，淡化采样数 `F`（由毫秒换算得到）。对片段内相对下标 `i`（`0 .. L−1`）：

- 淡入：`i ∈ [0, F−1]` 时增益 `i / F`。端点 `i = 0` 增益为 0；`i = F` 增益为 1，但 `i = F` 已在淡化区之外。
- 淡出：`i ∈ [L−F, L−1]` 时增益 `(L − i) / F`。端点 `i = L−F` 增益为 1；右端点 `i = L` 增益为 0，但 `i = L` 不包含在片段内。
- 总增益 = 淡入增益 × 淡出增益（逐采样相乘）。
- `F = 0` 表示不淡化。
- 约束：`fadeInSamples + fadeOutSamples <= length`，两段淡化**不得重叠**；恰好相邻（`=== length`）允许，交界处两式都给 1。
- 每个片段写入输出的采样数恒为 `length`，淡化不影响任何长度。

### 量化

浮点幅度先夹取到 `[−32768, 32767]`，再做 half-away-from-zero 四舍五入成 16 位整数。

### 拼接与静音

- 严格按列表当前顺序拼接；相邻片段之间插入指定数量的**零值采样**（首尾不加）。
- 输出长度 = `Σ 片段长度 + 静音数 × (片段数 − 1)`，界面实时显示。

### 拒绝与不覆盖

- 不支持的格式（非 WAV、多声道、非 16 位、压缩格式、缺块/截断等）在导入时即被拒绝。
- 负静音、负淡化、淡化重叠、零长度/越界/逆序区间均报错。
- **尚无片段时不能导出**（不会产生伪装成功的空文件）。
- 任何非法操作只弹错误提示，当前有效编辑状态保持不变。

## 来源说明 manifest.json

每次导出同时写入，记录（节选）：

- `output`：文件名、采样率、声道/位深/编码、**总采样数**与时长；
- `source`：源文件名、采样率、采样数、时长、原始字节 **SHA-256**；
- `conventions`：上述全部换算与端点规则；
- `timeline`：逐条记录每个片段的
  - `sourceStartSample/sourceEndSample`（来源区间，左闭右开）与对应毫秒，
  - 淡入/淡出采样数，`lengthSamples`，
  - `outputStartSample/outputEndSample`（**最终输出位置**），
  - 以及片段间 `silence` 条目的长度与输出位置。

仅凭 manifest + 原始素材即可逐点重建输出（测试中有独立重建并逐采样比对的用例）。

## 目录结构

```
src/
  errors.js     # EditError 与错误码
  wav.js        # 16-bit mono PCM WAV 解码/编码（纯函数）
  model.js      # 区间校验、毫秒换算、淡化、不可变编辑、渲染、manifest
web/
  waveform.js   # Canvas 波形绘制与拖选坐标映射
  app.js        # 页面状态与交互（调用 src/ 纯函数）
  styles.css
index.html
server.js       # 零依赖静态服务器（--port 0）
test/           # node --test 自动化测试
```

## 备注

- 工具只做样本复制与幅度缩放，不重采样；输出采样率与源相同。
- 所有处理在浏览器内完成，文件不会上传到任何地方。
